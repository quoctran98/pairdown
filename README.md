# pairdown
I built a CLI tool to downsample (pare down, get it?) paired end FASTQs, because I couldn't find one for some reason, though I'm sure one exists. If you do find one, don't tell, otherwise I'll feel like I wasted my time doing this.


## Example Usage

```
pairdown read1.fq read2.fq 12000000 -o downsampled_ -s 17
```
